# Daylight Task Manager

A responsive task manager built with React and Vite. Add tasks with a category, priority, and due date; search and filter your list; mark items complete or remove them. Tasks are saved in this browser using `localStorage`.

## Run the app

Install Node.js, open a terminal in this folder, and run:

```bash
npm install
npm run dev
```

Open the local address shown in the terminal. To create a production build, run `npm run build`.

## Notes

- Tasks stay in the browser where they were created. This starter app does not use a server or sync tasks across devices.
- If PowerShell blocks `npm.ps1`, use Command Prompt in VS Code, or run `npm.cmd install` and `npm.cmd run dev` in PowerShell.
